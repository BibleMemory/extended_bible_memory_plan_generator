You build the widget UI in vanilla JS (no frameworks, zero runtime
dependencies): the input form with defaults, the >160-verse beginner
callout, semantic plan-table rendering (<table>/<thead>/<tbody>), the Print
button, and the bootstrap that mounts on [data-bible-memory-plan]. Follow
the markup contract (class names) supplied by the coordinator exactly — the
stylesheet is written against it.
